
# SpendWise Dashboard Shell

## Project Overview

SpendWise is a responsive personal finance dashboard designed to help users monitor their monthly budgets and expenses.

This project focuses on building a modern dashboard interface using HTML5 and CSS3.

## Features

- Sidebar navigation menu
- Dashboard header
- Monthly budget overview
- Six expense category cards:
  - Food
  - Transport
  - Rent
  - Entertainment
  - Savings
  - Utilities
- Responsive dashboard layout
- CSS Grid and Flexbox
- CSS custom properties
- Hover and keyboard focus animations
- Automatic dark theme support

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox
- CSS Variables
- Google Fonts

## Responsive Design

The dashboard adapts to smaller screens using a media query below 768px.
